# 沐車所｜MUCAR 線上預約系統

代客牽車洗車服務的形象網站：線上預約（匯款／現場付款）＋ 店家後台（訂單、時段、車型計價、客戶 CRM）。
前端是純靜態網頁（放 GitHub Pages），後端是 Google Apps Script + Google 試算表。

```
index.html          首頁（價目、服務流程、代客牽車注意事項）
booking.html        客人線上預約（5 步驟）
lookup.html         客人自助查詢 / 取消預約
admin.html          店家後台（首頁最下方「店家後台」連結，或直接輸入 /admin.html）
assets/config.js    ★ 設定檔（Apps Script 網址、店名、LINE、收款帳號）
assets/*.js|css     其餘程式與樣式（不用改）
Code.gs             ★ 不要上傳 GitHub！這是要貼進 Apps Script 的後端（已寫進 .gitignore）
```

---

## 一、最常見的三個坑（先看這裡）

| 症狀 | 原因 / 解法 |
|---|---|
| 改了 `config.js` 但網站完全沒變 | 網頁讀的是 **`assets/config.js`**。如果你把 `config.js` 放在 repo 最外層，網頁根本不會讀它。請編輯 `assets/config.js`。改完等 1～2 分鐘，並強制重新整理（Ctrl+F5 / 手機清除快取）。 |
| 預約頁「選車型」是空的、下一步按不動 | `API_URL` 填錯了。要填 **Apps Script 部署後的「網頁應用程式」網址**（`https://script.google.com/macros/s/……/exec`），**不是** Google 試算表網址（`docs.google.com/spreadsheets/...`）。填錯時網頁頂端會出現紅色提示。 |
| 後台登入顯示「尚未設定後台密碼」 | `Code.gs` 的 `ADMIN_KEY` 還是預設值 `change-me-0000`，系統刻意鎖住。請改成自己的密碼並重新部署。 |

## 二、後端（Apps Script，只需做一次；之後改版只要重貼）

### 1. 貼上程式碼
到 [script.google.com](https://script.google.com) 開專案 → 把 `Code.gs` **全部內容**貼進編輯器（覆蓋原本的）→ 存檔。

**貼完後，把最上面這行改成你自己的後台密碼**（每次整份重貼都要再改一次）：
```js
var ADMIN_KEY = '你自己的後台密碼';
```
`PUBLIC_KEY` 要跟 `assets/config.js` 的 `PUBLIC_KEY` 一致（目前都是 `qazb5566`）。
**`ADMIN_KEY` 一定要和 `PUBLIC_KEY` 不一樣**（前台金鑰任何人看網頁原始碼就拿得到；兩者相同時，後台功能會被系統鎖住並提示）。

### 2. 建表
函式選單選 **`setup`** → 執行 → 授權。第一次會**自動建立一個 Google 試算表**當資料庫（網址在「執行記錄」，或執行 `getSheetUrl`）。
`setup` 可重複執行，不會蓋掉你的資料；**更新版本後也請再跑一次**（會補上新欄位）。就算忘了跑，客人第一次打開預約頁時，系統也會自動補上級距與車型資料。

### 3. 部署（重點：要用「新版本」）
- 第一次：**部署 → 新增部署作業 → 網頁應用程式**，執行身分「我」、存取權「任何人」。
- 之後改程式：**部署 → 管理部署作業 → 鉛筆(編輯) → 版本選「新版本」→ 部署**，網址才不會變。
- 複製「網頁應用程式網址」（結尾 `/exec`）。

### 4. 驗證
瀏覽器開你的 `/exec` 網址，看到 `{"ok":true,"data":{"time":...,"version":"3"}}` 就成功了。

### 5.（選用）保溫
執行一次 **`installKeepWarm`**，每 5 分鐘自動戳一下後端，減少冷啟動。

## 三、前端（GitHub Pages）

1. 編輯 **`assets/config.js`**，把 `API_URL` 換成上一步的 `/exec` 網址。
2. 上傳到 repo 根目錄：`index.html`、`booking.html`、`lookup.html`、`admin.html`、`assets/` 整個資料夾。
3. **Settings → Pages → Deploy from a branch → `main` / `(root)`**。
4. 網址是 `https://你的帳號.github.io/repo名稱/`。

> HTML 裡的 `?v=3` 是快取版本號，之後更新 JS/CSS 想確保客人立刻拿到新版，可以把它改成 `?v=4`（每個 html 檔的每個 `assets/…` 都要一起改）。

## 四、系統邏輯

### 預約流程（客人）
1. 基本資料（姓名、電話必填；生日、LINE、備註選填）
2. 選車型：先選廠牌再選型號，系統依級距自動判定價格；找不到車可選「其他」並填車款，由店家事後報價
3. **牽車地址** + 日期 + 時段（每半小時一個起始時間）
4. 付款方式：匯款（顯示收款帳號）或現場付款。匯款的客人**不用在網站填末五碼**，只會被提醒：匯款後把截圖與轉出帳號末五碼傳到官方 LINE
5. 確認內容並勾選同意「服務須知」→ 送出

送出後畫面會顯示訂單編號；選匯款的客人會拿到一段可複製的「網購匯款通知」範本（訂單編號、姓名、電話、金額已帶入；匯款日期與末五碼留空給客人在 LINE 自己填），貼到官方 LINE 並附上匯款截圖，由店家人工核對。

### 時段規則
- 營業時間：當天 12:00 → 隔天 03:00；每筆預約佔用一段連續時間（預設 3 小時，後台可切 2 小時），同一時段只接一組。
- 已過去的時段、已被預約的時段、後台關閉的時段都不能選。
- 後台可「關閉整天」或「只關閉某個時間範圍」。

### 費用
- 洗車費用依車型級距（小型車 $550／中型車 $650／小型SUV $700／大型休旅 $800／7人座 $1100，可在後台改）。
- **牽車費用依實際距離評估**，由店家確認後通知；店家可在後台訂單裡把金額改成含牽車費的最終金額。

### 匯款核對
後台訂單詳情有「標記為已核對」——純粹是店家的記事欄位，**不影響預約是否成立、也不影響消費次數**。若發現沒付款，請直接在後台「取消預約」。

### CRM
- 用電話辨識同一位客人；每筆預約算一次消費，取消會扣回次數與金額。
- 客人重複預約（已有未來的進行中預約）時會跳出確認視窗，但不擋單。
- 客人只能在預約時間之前自行取消；之後請聯繫官方 LINE，或由後台取消。

### 後台
- 入口：首頁最下方「店家後台」連結，或直接開 `你的網址/admin.html`（例如 https://mucarso5566.github.io/MUCAR/admin.html）。
- 登入密碼：就是你在 `Code.gs` 設定的 **`ADMIN_KEY`**（不是前台金鑰 `qazb5566`；填前台金鑰會被擋下）。密碼只會記在你登入的那台裝置的瀏覽器，按右上角「登出」即清除。
- 如果後台上方出現黃色「後端程式還不是最新版」，代表 Apps Script 部署的還是舊版，請重新貼 `Code.gs` 並用「編輯 → 新版本」部署。
- 預約訂單：日期/狀態篩選、點開看完整資料（地址可一鍵開地圖、客人備註）、改金額、內部備註、核對、取消。
- 時段設定：時段長度 2/3 小時、公休與時段關閉。
- 車型計價：級距價格、廠牌型號對照（新增/停用/刪除）。
- 客戶 CRM：搜尋、消費次數與累計金額、每位客人的預約紀錄。

## 五、安全提醒
- 前台金鑰（`PUBLIC_KEY`）寫在網頁裡，任何人看得到，只用來擋亂打的請求；真正保護後台的是 `ADMIN_KEY`（只存在 Apps Script 與你登入後的瀏覽器）。
- 客人輸入的內容顯示在後台前都會先跳脫，寫進試算表前會中和以 `=` `+` `-` `@` 開頭的公式。
- `Code.gs` 請不要上傳到公開的 GitHub repo。
